# IAC 格式规范（IAC Format Specification）

版本：1.0
状态：草案

## 1. 概述

IAC（全称 Inline Annotation Container）是一种字幕描述格式，专为游戏开发设计，使用 `.iac` 或有时 `.txt` 作为文件扩展名。

IAC 文件为 UTF-8 编码的纯文本，换行符建议使用 LF（`\n`）。文件由**注释行**、**记录行**和**空行**组成。

## 2. 文件结构

一个 IAC 文件包含若干可选的注释与若干记录行。记录行之间允许插入空行和注释行以增强可读性。

```
# 注释
记录行1

# 注释
记录行2
```

## 3. 词法规则

### 3.1 注释

以 `#` 开头的行均为注释，解析器应忽略其内容。注释可出现在文件任意位置，对记录行无影响。

```
# 这是一个注释
# This is a comment
```

### 3.2 空行

空行（仅包含空白字符或完全为空）允许出现在任意位置，解析器应忽略。

### 3.3 分隔符

记录行使用 ` : `（空格 + 冒号 + 空格）作为字段分隔符。字段内部不应出现该序列。

## 4. 记录行语法

每条记录行描述一条音频轨道及其关联字幕，语法如下：

```
<AudioName> : {<SubtitleEntry>[, <SubtitleEntry>...]} : [<Color>] : <Enabled>[ : <Type>]
```

字段顺序固定，从左到右依次为：

| 序号 | 字段       | 必填 | 说明                     |
|------|------------|------|--------------------------|
| 1    | AudioName  | 是   | 音频轨道名称             |
| 2    | Subtitles  | 是   | 字幕条目集合             |
| 3    | Color      | 是   | 字幕显示颜色             |
| 4    | Enabled    | 暂定 | 名称用途暂定（自定义布尔值）|
| 5    | Type       | 否   | 轨道类型标识（自定义字符串）|

### 4.1 AudioName（音频名称）

标识一条音频轨道，在同一文件内应唯一。允许包含字母、数字、下划线（`_`）和空格。名称为第一个 ` : ` 之前的全部内容。

示例：
- `Level1VO1`
- `music_KnewBefore`
- `Jay Finale 18 T2_Sec1`

### 4.2 Subtitles（字幕集合）

由一对大括号 `{}` 包裹，内部为一项或多项字幕条目，条目之间以 `, `（逗号 + 空格）分隔。

```
{<SubtitleEntry>, <SubtitleEntry>, ...}
```

#### 4.2.1 字幕条目

每条字幕条目由文本和时间区间组成：

```
"<Text>"|<StartTime>-<StopTime>|
```

- **Text（文本）**：用半角双引号 `"` 包裹的字幕内容。文本可为任意 Unicode 字符（含中文、英文、标点、空格、括号等），但不能包含未转义的双引号。若文本中需要包含双引号，应使用 `\"` 转义。
- **时间区间**：用竖线 `|` 包裹，内部为 `<StartTime>-<StopTime>`，起始与结束时间以连字符 `-` 连接。

示例：
```
"TEXT 1"|00:00:00:22-00:00:02:02|
"那地方看起来或许很平静，但……"|00:00:00:12-00:00:02:45|
```

### 4.3 时间格式

时间采用 `HH:MM:SS:CC` 四段式表示，各段均为两位数字，不足补零：

| 段 | 含义        | 取值范围   |
|----|-------------|------------|
| HH | 小时        | 00–99      |
| MM | 分钟        | 00–59      |
| SS | 秒          | 00–59      |
| CC | 百分秒（1/100 秒） | 00–99 |

示例：`00:00:17:20` 表示 0 小时 0 分 17.20 秒。

约束：
- `StartTime` 必须小于或等于 `StopTime`。
- 同一条记录内，相邻字幕条目的时间区间允许不连续（存在间隙），但不建议重叠。

### 4.4 Color（颜色）

用方括号 `[]` 包裹的十六进制颜色值，格式为 `#RRGGBB`，大小写不敏感。

示例：`[#FFFFFF]` 表示白色。

### 4.5 Enabled（启用标志）

布尔值，控制该条记录是否生效：
- `true`：启用，字幕正常显示。
- `false`：禁用（如已删除或暂不使用的台词），解析器应跳过或标记为不渲染。

示例中 `Level1VO2 : {...} : [#FFFFFF] : false` 表示该台词被删除/禁用。

### 4.6 Type（类型标识，可选）

当存在第 5 个字段时，标识该音频轨道的类型。当前规范定义如下取值：

| 取值   | 含义                       |
|--------|----------------------------|
| Music  | 音乐轨道（歌词）           |

未指定 Type 字段时，默认为普通字幕轨道（语音/台词）。

示例：
```
music_KnewBefore : {...} : [#FFFFFF] : true : Music
```

## 5. 完整示例

### 5.1 单条字幕（含中文台词）

```
Jay Finale 18 T2_Sec1 : {"那地方看起来或许很平静，但……"|00:00:00:12-00:00:02:45|, "并不是这样……"|00:00:03:19-00:00:04:19|, "那有某种……"|00:00:04:41-00:00:06:09|, "敌对的东西。"|00:00:06:87-00:00:08:72|} : [#FFFFFF] : true
```

### 5.2 多条记录（含禁用项）

```
Level1VO1 : {"TEXT 1"|00:00:00:22-00:00:02:02|, "TEXT 2"|00:00:02:28-00:00:03:06|} : [#FFFFFF] : true
Level1VO2 : {"A deleted line"|00:00:00:29-00:00:00:92|} : [#FFFFFF] : false
Level1VO3 : {"TEST TEXT"|00:00:00:24-00:00:02:34|, "TEST TEXT"|00:00:02:50-00:00:03:15|} : [#FFFFFF] : true
```

### 5.3 音乐歌词轨道

```
music_KnewBefore : {"I've forgot the way to be myself"|00:00:08:58-00:00:17:20|, "I don't know who I was the night before"|00:00:17:20-00:00:25:99|, ...} : [#FFFFFF] : true : Music
```

## 6. 解析规则摘要

1. 按行读取文件，去除行尾换行符。
2. 跳过空行与以 `#` 开头的注释行。
3. 对剩余行，按 ` : ` 从左至右切分字段。
4. 第 1 字段为 AudioName。
5. 第 2 字段去除首尾 `{}` 后，按 `, ` 切分为字幕条目；每条按 `"..."|...-...|` 解析文本与时间。
6. 第 3 字段去除首尾 `[]` 得到颜色值。
7. 第 4 字段解析为布尔值（`true`/`false`）。
8. 若存在第 5 字段，作为 Type；否则 Type 默认为普通字幕。

## 7. 扩展约定

- 新增 Type 取值应在本规范中登记，避免与现有用途冲突。
- 颜色字段未来可扩展为支持 `#RRGGBBAA`（含透明度），解析器应忽略长度不符的值或按本规范严格校验。
- 时间精度固定为百分秒，不应使用其他精度。
